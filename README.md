# Smartly – Access Flow Control Management System

Smartly is a web-based campus resource management system that simplifies classroom and laboratory bookings, room availability tracking, and request approvals.

## Features
- Student, Faculty, and Admin dashboards
- Room availability search and filtering
- Classroom and laboratory booking
- Booking request approval and rejection
- Resource and user management
- Profile and password management

## Tech Stack
- **Frontend:** React.js, JavaScript, HTML, CSS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / MySQL (as implemented)

## Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd smartly

# Frontend
cd frontend
npm install
npm run dev
```

Run the backend separately using its configured npm script.

## Objective
To digitize campus resource management, simplify room reservations, and improve resource utilization.
